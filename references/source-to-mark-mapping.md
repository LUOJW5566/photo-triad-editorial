# Source-to-Mark Mapping

Use this worksheet before generation. It keeps the lower panel faithful to the uploaded photograph while allowing a nonliteral visual language.

## Source dossier

Record only observable facts:

```text
ANCHOR:
WHY DISTINCTIVE:
MAJOR MASSES:
PRIMARY AXIS OR DIRECTION:
DEPTH ORDER:
RHYTHM / COUNT / INTERVALS:
OVERLAP OR OCCLUSION:
NEGATIVE SPACE:
LIGHT DIRECTION / BRIGHTEST REGION:
COLOR ROLES:
MOOD / EMOTIONAL TEMPERATURE:
```

Select one primary fact and no more than two supporting relationships. If the source has no dominant object, use its strongest spatial gesture, density, horizon, reflection, or color relationship instead of inventing a subject.

## Mapping vocabulary

| Observable source fact | Isometric translation | 3D translation | Pixel translation |
|---|---|---|---|
| Large mass or field | oblique plane or stepped region | layered/extruded matte volume | broad block field with lost corners |
| Horizon, road, shore, or roofline | measured oblique or horizontal axis | shallow slab/contact plane | segmented bar with gaps |
| Direction or motion | receding axis or aligned planes | tapered overlap or depth sequence | stepped streak or block chain |
| Repeated objects or lights | offset modules with source rhythm | grouped volumes at varied depth | repeated coarse blocks with uneven intervals |
| Enclosure or opening | framed void between planes | nested/occluding volumes | negative notch or missing block region |
| Reflection or shadow | offset parallel plane | lighter/darker echo with contact | shortened low-contrast block echo |
| Organic cluster | irregular oblique mass | overlapping soft-edged volumes | broken block cloud with selective erosion |
| Person or narrow object | one compact axis-aligned/oblique mark | one shallow volume | one irregular vertical or block form |

## Fusion rules

1. Assign each visible lower-panel element to a source fact before generation.
2. Use isometric geometry for organization, not as a decorative grid.
3. Use 3D volume only where depth, overlap, or material is present in the source.
4. Use pixel blocks to simplify and interrupt the form, not to cover the entire canvas.
5. Keep the same dominant light direction and color hierarchy in all three languages.
6. Preserve source asymmetry, relative dominance, spacing, and negative-space direction.
7. Permit displacement, compression, separation, overlap, and rescaling only when the change clarifies a named relationship.
8. Stop adding marks when the source is recognizable through its relationships. Empty space is preferable to low-information detail.

## Prompt skeleton

```text
Source anchor: [one distinctive subject or relationship]
Retained facts: [mass], [axis/direction], [rhythm/overlap/negative space]
Isometric role: [planes/axes/stepped depth]
3D role: [volume/occlusion/material/contact]
Pixel role: [coarse blocks/stepped erosion/broken contour]
Palette: [source-derived roles only]
Placement: [lower-panel position and reason]
Omit: [surface detail, incidental objects, unsupported decoration]
```
